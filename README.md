# Word lists for Italian, Spanish, French and German

Free frequency word lists for language learners: the most common words of each language, with lemma and English meaning, as CSV and plain text. Made by [Apera](https://apera.me), which helps you learn the words in what you read.

## Two kinds of list

- **Speaking**: the words of everyday spoken language, ranked using published film and TV subtitle word counts. Start here.
- **Reading**: the words that rank high in news, sports, food or tech writing, counted by Apera from web pages. Useful once you read about a subject you care about.

Every file has the columns `rank,word,lemma,meaning`. Each written form of a word is its own row (Italian *è* and *sono* both appear). The last row of each CSV carries the licence and a link to the credits.
